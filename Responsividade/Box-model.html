Caixa

  • box-level:

    • - ocupa uma linha inteira

    - o próximo elemento vai para linha de baixo automatico

    exemplo: de tag <div>, <h1> até <h6>, <p>, <main>

  • inline-level:

    • - não quebra linha

    - pode ficar ao lado de outras tags inline

    se a tela for pequena, os elementos inline podem quebrar para a próxima linha (visual feio)

    exemplo: de tag <span>, <a>, <strong>, <em>
