Flexbox - Modelo de Layout Flexível

Características:

- trabalha com caixas flexíveis

- permite que os elementos de uma caixa se adaptem ao espaço disponível

Entendendo o conceito de eixos em Flexbox:

- Eixo principal (main axis): é a direção em que os itens flexíveis são organizados. Pode ser horizontal (row) ou vertical (column).

- Eixo transversal (cross axis): é a direção perpendicular ao eixo principal. Se o eixo principal for horizontal, o eixo transversal será vertical, e vice-versa.

Propriedades do container flexível:

  • display: flex;

    • - ativa o Flexbox para o container

  • flex-direction: define a direção dos itens
