Resumo das Tags de Formatação

ítalico da ênfase com a tag em

negrito da destaque com a tag strong

marcação de texto da destaque com a tag mark

texto riscado da indicação de que o texto foi removido com a tag del

texto sublinhado da indicação de que o texto foi adicionado com a tag ins

para escrever numeros elevado a potencias 422 usa a tag sup

para escrever numeros em fórmulas com numeros em baixo tipo H2O usa a tag sub

escrever códigos de forma mais visual utilize a tag code

para escrever códigos com mais de uma linha use a tag pre para organizar:

  
  if (x >= 10){
    echo "x é maior ou igual a 10";
  } else {
    echo "x é menor que 10";
  }

para citar frases use a tag quoteela adiciona aspas ao texto

para citar um trecho de texto maior use a tag blockquote:

ela adiciona uma indentação ao texto. Também é possivel adicionar a fonte da citação com o atributo cite.

você pode colocar significados de abreviações de forma oculta em HTML com a tag abbr
